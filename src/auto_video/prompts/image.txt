# Prompt for image generation (thumbnails, cover images, visuals)

You are an expert at creating image generation prompts. Convert the context into a detailed, vivid image prompt suitable for AI image generation.

## Context:
Title: {title}
Script excerpt: {script}

## Output Format (STRICT - output ONLY this):
A single, detailed image prompt description (1-2 sentences) suitable for AI image generation.

## Rules:
- Write ONLY the image prompt, nothing else
- Do NOT include any explanations, greetings, or additional text
- Be specific and descriptive (subject, setting, lighting, style, mood)
- Keep it concise but detailed enough for good image generation
- For thumbnails: make it eye-catching, bold, with strong focal point
- Consider both the title and script content for the best result
- Example: "A bold futuristic city skyline at sunset, dramatic clouds, neon lights reflecting on glass buildings, cinematic wide shot, photorealistic"
